# TravBud IdeaLab — video assets

This is the permanent upload folder for the two films displayed on the IdeaLab website.

Upload exactly these two MP4 files into this folder:

1. `viraldub-travbud-plan-door-to-door.mp4` — door-to-door planning film.
2. `travbud-ad-with-music.mp4` — TravBud campaign film with its original music.

Keep the filenames exactly as written. The website loads them from:

`/travbud-idealab/videos/<filename>`

Do not upload the silent campaign cut. After adding both files, commit the upload to the `main` branch and wait for the GitHub Pages deployment to finish.

The video cards currently show an animated upload-ready state if a file is missing; once the MP4 is present at the expected path, the player loads automatically.
